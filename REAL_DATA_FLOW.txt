CryptoScanner — Real Trading Data Flow

REAL AUTO TRADING — RIDE FORMING TRENDS
1. Nobitex /market/stats (IRT/Rial markets) -> live local universe and books.
2. CoinMarketCap listings + quotes for overlapping symbols -> USD prices this cycle.
3. Engine stores CMC USD and Nobitex ask every scan and measures lookback movement.
4. A coin stays a candidate when the observed path (or CMC 1h) is still up
   for consecutive scans, and quality filters pass (spread, volume, freshness,
   BTC dump, fade). Nobitex already moving with the trend is allowed.
5. It does not require Nobitex to be cheaper than CMC × USDT/IRT.
6. It does not use RSI / MACD / moving-average gates.
7. Confirmed candidates go to the live SignalTracker. Paper Trading gets the
   same engine rows plus the full Nobitex book so open paper trades can trail/exit.
8. Real SignalTracker -> TradingBot -> Nobitex order API.
9. Fill confirmation -> native stop_market -> trailing -> exit.

IMPORTANT
- CoinMarketCap is intelligence only; it never receives orders.
- Nobitex is the sole execution venue.
- IRT balances and size are Rial, matching the Nobitex wallet.
- Trading size, stops, and trend filters live in SmartEagle Bot → Settings.
- Scanner Settings is market-data API / display only.

LOGGING

- [PAPER] = paper workflow
- [REAL][SAFETY] = protective-stop / emergency-exit
